# holyrics-sdk-dart

Unofficial Dart & Flutter SDK for the [Holyrics](https://holyrics.com.br/)
API Server (lyrics, presentation control, playlists, media, settings...).

| Package | Description |
| --- | --- |
| [`holyrics_core`](packages/holyrics_core) | Protocol layer: transports (local token/hash, cloud relay), raw action methods for the whole API and typed domain models. Pure Dart. |

The full API documentation is vendored in [`docs/api`](docs/api).
Design decisions live in [`docs/DECISIONS.md`](docs/DECISIONS.md); see
[`CONTRIBUTING.md`](CONTRIBUTING.md) before sending changes.
